# FarmShare USA — Asset Prompt Pack (Stills → Videos, paired)

> Generate these **before** handing the site to Claude Design, so the design is built around real assets.
> **Stills:** built for **ChatGPT's image generator**.
> **Videos:** built for **LMArena image-to-video** (lmarena.ai/video) — you upload a still + a motion prompt.
> Art direction = **"The Living Almanac"** (see `claude-design-brief.md`).

---

## How this document works (read once)

This pack has two parts:

- **PART 1 — VIDEOS (paired).** Every video is two steps:
  - **[N]A · STILL** = the detailed ChatGPT prompt to create the **starting frame**. Generate it, download it, name it as noted.
  - **[N]B · VIDEO** = the detailed LMArena prompt. You **upload the still from [N]A**, paste this prompt, and LMArena returns two model takes — pick the best.
- **PART 2 — STILL-ONLY IMAGES.** Page assets that don't need a video — just ChatGPT still prompts.

**Three rules that matter:**
1. **A video copies its still's shape.** Want a widescreen 16:9 hero clip? The still in step A must be 16:9. Want a vertical 9:16 clip for mobile/social? Make that still 9:16.
2. **In a [N]B video prompt, describe only MOTION** (camera, breeze, light, particles, pace). The scene already comes from the uploaded still — don't re-describe it.
3. **Keep ChatGPT stills consistent:** after your first image, add *"Use the exact same art direction, color grade, and lighting as the previous image"* to each new still prompt. Every still prompt below also ends with the full style line so it works standalone.

**Aspect ratio in ChatGPT:** just say the shape in words — *"wide 16:9 horizontal,"* *"vertical 9:16,"* *"square 1:1,"* *"portrait 4:5."*
